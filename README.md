# Library Management System

Проєкт реалізовано з використанням TypeScript, Vite та Bootstrap.
Рендеринг інтерфейсу виконується виключно через DOM API, збереження стану — в LocalStorage.

## Скрипти
- `npm run start` — запуск dev-сервера
- `npm run build` — продакшн збірка (включає перевірку типів)
- `npm run test` — запуск юніт-тестів (Mocha/Chai)
- `npm run lint` — перевірка ESLint
- `npm run format` — форматування Prettier

## Висновок: Порівняння Webpack та Vite

На основі досвіду розробки та міграції цього SPA-проєкту, нижче наведено порівняльний аналіз Webpack та Vite.

* **Швидкість старту dev-сервера та HMR:** 
Vite виграє з великим відривом. Dev-сервер Vite стартує миттєво, 
Webpack змушений аналізувати та збирати весь граф залежностей у пам'яті перед запуском, що спричиняло помітні затримки навіть на невеликому проєкті.

* **Час і складність налаштування:** 
Конфігурація Webpack потребувала ручного підключення плагінів (наприклад, `html-webpack-plugin`) та лоадерів для кожного типу файлів. 
Налаштування Vite зайняло кілька хвилин: мінімальний файл `vite.config.ts` та зміна імпорту в `index.html`.

* **Підключення UI-фреймворку та TS-лоадерів:** 
У Webpack імпорт Bootstrap (`.css`) та TypeScript вимагав встановлення `style-loader`, `css-loader` та `ts-loader`. 
Vite підтримує ці формати з коробки — імпорти запрацювали одразу після встановлення залежностей без модифікації конфігу.

* **Розмір і швидкість продакшн-збірки:** 
Vite використовує Rollup для продакшн-збірки, яка виконується швидше за рахунок попередньої компіляції. 
Розміри фінальних бандлів (JS/CSS) концептуально схожі, але Rollup агресивніше виконує tree-shaking, залишаючи менше мертвого коду.

* **Екосистема плагінів:** 
Webpack має гігантську екосистему, яка накопичувалася роками, проте багато рішень є перевантаженими або застарілими. 
Екосистема Vite (яка спирається на Rollup) є більш сучасною та повністю покриває потреби сучасного фронтенду без конфліктів залежностей.

* **Суб’єктивна оцінка для невеликих SPA:** 
Для проєктів подібного масштабу Webpack є абсолютно надлишковим інструментом, що генерує boilerplate-код і витрачає час розробника. 
* Vite є безальтернативним вибором, швидкодії та принципу "zero-config" для базових завдань.
